# Agente Geo Farming · Centro de Mando

Extensión de Brave/Chrome (Manifest V3) con los robots de prospección inmobiliaria: Propi, Chequi, Veri, Owny, Lofti, Wibi, Carpi, Texi, Resi, Limpi, Marki, Zeta, Redi, Radar, Termi y Capi.

## Instalar
1. Abre `brave://extensions` (o `chrome://extensions`) y prende **Modo de desarrollador**.
2. **Cargar descomprimida** → escoge esta carpeta.

Las llaves (Lofty, Census, etc.) se ponen dentro de la extensión; no van en el código.
